# Contributing to MediMate

Thank you for your interest in improving MediMate!

## How to Contribute

1. Check existing issues before reporting a duplicate.
2. Open an issue to describe a bug or propose an improvement.
3. Fork the repository and create a branch for your changes.
4. Make focused changes and test them before submitting.
5. Open a pull request describing the changes and the tests performed.

## Contribution Guidelines

- Keep changes focused and easy to review.
- Follow the existing project structure and coding style.
- Do not commit credentials, `.env` files, or private patient information.
- Do not include real medical records in screenshots or test data.
- Explain any important changes in your pull request.

Thank you for helping make MediMate better!
