# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in MediMate, please report it privately to the repository owner rather than publishing sensitive details in a public issue.

Include:
- A description of the potential vulnerability.
- Steps to reproduce it.
- The possible impact, if known.

Never include real patient information, passwords, access tokens, or other sensitive data in a report.

## Security Best Practices

- Never commit `.env` files, credentials, or private keys.
- Keep project dependencies updated.
- Restrict access to patient information to authorized users.
- Use test data when reporting bugs.

MediMate is a student project and is not a substitute for professional medical advice or emergency healthcare services.
